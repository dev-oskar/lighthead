# StatTile

One number with its label, an optional seven-point sparkline and a short note.

- Props: `label`, `value` (string, preformatted), `unit`, `trend` (array of numbers, oldest first), `note`, `tone` `moss | resin | tide`.
- Notes compare without judging: "0.4 g less than last week", never "Great job".
- Group tiles in rows of two or three; each tile states one figure.

# StrainBadge

Small tag for a strain's type. Each type owns a hue: indica `dusk`, sativa `resin`, hybrid `moss`, CBD-dominant `tide`.

- Props: `type` `indica | sativa | hybrid | cbd`; children overrides the label.
- Always shows the word; the colour is a second cue.
- Use these four hues only for strain types, so a colour always means the same thing.

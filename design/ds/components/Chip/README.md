# Chip

Toggle tags for effects, moods and filters. Selected chips show a check and the moss tint, so state never relies on colour alone.

- Props: `selected` + `onChange(bool)` when controlled, or `defaultSelected`; `disabled`; children is the label.
- Use for multi-select lists of up to about twelve options. For one-of-many, use SegmentedControl.
- Labels are one word, capitalised: Calm, Creative, Sleepy.
